Student Management System

Project Overview

The Student Management System is a Python-based application designed to manage student information easily and efficiently. It helps to store, update, view, and delete student records.

This project uses Jira for project management and GitHub for version control and CI/CD.

Objectives

- To manage student records digitally.
- To reduce manual paperwork.
- To make student information easy to access.
- To improve data management and accuracy.

Features

- Add new student details.
- View student records.
- Update student information.
- Delete student records.
- Manage student data efficiently.

Technologies Used

- Python: For application development.
- Jira: For task tracking and project management.
- GitHub: For source code management.
- GitHub Actions: For CI/CD automation.

Project Workflow

1. Plan project tasks using Jira.
2. Develop the application using Python.
3. Upload source code to GitHub.
4. Track changes using Git.
5. Use GitHub Actions for automated testing and CI/CD.

Installation and Setup

1. Install Python on your computer.

2. Clone this repository:
   
   "git clone YOUR_REPOSITORY_URL"

3. Open the project folder.

4. Run the Python application:
   
   "python main.py"

Advantages

- Easy to use.
- Saves time.
- Reduces paperwork.
- Improves data accuracy.
- Makes student information management easier.

Future Enhancements

- Student login system.
- Attendance management.
- Fee management.
- Database integration.
- Report generation.

Conclusion

The Student Management System provides a simple and efficient way to manage student information using Python. Jira and GitHub CI/CD help in better project management and software development.
